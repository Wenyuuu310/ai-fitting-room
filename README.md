# AI 试衣间 使用说明

在线使用：https://wenyuuu310.github.io/ai-fitting-room/ （手机打开后可"添加到主屏幕"）

一个完全免费、在你电脑浏览器里运行的小网页：上传照片和衣服图片后，它会生成试穿效果图，推荐尺码，并告诉你值不值得买。

## 第一次使用（大约 5 分钟）

1. **打开网页**：双击文件夹里的 `index.html`，用 Chrome 或 Edge 打开。
2. **申请免费的 Gemini Key**（用来做尺码推荐和购买建议）
   - 打开 https://aistudio.google.com/apikey ，用 Google 账号登录
   - 点 “Create API key”，复制以 `AIza` 开头的那串字符
3. **申请免费的 Hugging Face Token**（用来生成试穿图，不填也能试，但额度很少）
   - 在 https://huggingface.co 注册账号
   - 打开 https://huggingface.co/settings/tokens ，点 “Create new token”，类型选 **Read**，复制以 `hf_` 开头的字符
4. 回到网页，点右上角 **设置**，把两个 key 粘贴进去，点 **保存**。

Key 只保存在你这台电脑的浏览器里，不会上传到别处。

## 每次使用

1. 上传你的照片，填身材数据（只需要填一次，会自动记住）
2. 上传衣服图片（截图也行），选择类型
3. 把尺码表粘贴成文字，或者上传尺码表截图
4. 点 **✨ 生成试穿图 + AI 分析**

小技巧：截图后可以直接在网页上按 `Ctrl + V` 粘贴图片，会依次填进“你的照片 → 衣服 → 尺码表”中还空着的那一格。

右上角的 **EN / 中文** 按钮可以切换语言。

## 需要知道的限制

- **完全免费，但有次数限制**：试穿图用的是 Hugging Face 上公开的模型（上衣用 IDM-VTON，裤子、裙子、连衣裙用 Leffa），免费账号每天的 GPU 额度大约够生成几张。用完会提示，第二天恢复。Gemini 免费版每天也有次数上限，自己用一般够。
- **生成一张图大约 30 到 90 秒**，有人排队时会更久。模型偶尔维护或休眠，等几分钟再试即可，或者在设置里换一个 IDM-VTON 的 Space。
- **记得选对「类型」**：选“裤子 / 半身裙”或“连衣裙”时会换成支持下装的模型。下装的效果一般比上衣差一点，裤子最好用全身照。
- **照片效果**：正面、站直、光线好、穿得贴身一点，生成效果最好。衣服图用平铺图或白底图最好。
- **隐私**：照片会发给 Hugging Face 上的试衣模型和 Google Gemini 处理。Gemini 免费版可能用你的数据改进产品，介意的话可以用不露脸的照片。

## 常见问题

- **提示 “model not found”**：去设置里把 Gemini 模型换成 AI Studio 里能看到的免费模型名（比如 `gemini-3.8-flash`；新版网页遇到这种提示会自动切换）。
- **提示 GPU 额度用完**：确认已填 Hugging Face Token，或者明天再试。
- **试穿一直转圈**：模型可能在排队或者在唤醒，耐心等两三分钟。

## 文件说明

- `app.js`、`styles.css`：网页的代码和样式
- `vendor/gradio-client.js`：连接 Hugging Face 模型用的开源库（@gradio/client 2.7.1）
